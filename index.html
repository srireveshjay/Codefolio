Submission privacy and limits

When you click Submit, your roll number, private submission code and three programs go to the configured submission service. That service checks your code against the private roster, records the official roster name and section, and saves your source in the faculty’s private GitHub repository. Drafts remain on this device. Your private code is not saved in browser storage.

Downloading a PDF without submitting does not add you to the submission log. The faculty dashboard needs a complete class roster to identify students who have not submitted. Repository submission is available only after the service is configured. Keep your private code confidential; sharing it permits someone else to submit under your roll number.

Copy/paste blocking can be bypassed. Templates are editable and placeholder checks do not evaluate algorithm correctness or prove authorship. There is no compiler or plagiarism checker. Unsupported PDF font characters produce an explicit error; use Print / Save as PDF for browser font fallback.
