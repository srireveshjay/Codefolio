What is recorded?

Clicking Download PDF generates the file locally, starts the browser download and then sends only the assignment ID and your roll number to record completion. The service uses the class roster to record your name, roll number, section and server submission time. It does not receive or save your programs, PDF, or a source-code hash. No student password, private submission code or sign-in is required.

Names and roll numbers are self-reported. Someone else could enter your roll number; this list is an acknowledgement, not proof of authorship or completed algorithms. Placeholder checks happen only in this browser and can be bypassed. Faculty can compare the list with their complete roster to see who has not recorded a submission.

Programs are held only in this tab's memory. There is no autosave; closing or refreshing can lose your work. Download your PDF first. Older drafts for this assignment are loaded into memory and removed from device storage when this updated page opens. Downloaded PDFs remain on your computer.

Copy/paste blocking can be bypassed. There is no compiler or plagiarism checker. Unsupported PDF characters produce an explicit error; use Print / Save as PDF for browser font fallback.
